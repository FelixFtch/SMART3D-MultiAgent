Stage 2 — Failed Optimization Attempts
What Didn't Work (and Why)
Two optimization routes explored and abandoned. Both instructive for understanding design constraints.
Route A: Only Check New Walls

Idea: update_new_static_obstacles() — only check new walls. O(N×w) instead of O(N×W).

Failed: Lazy swap leaves dirty edges. Route A only checks new walls → old dirty edges persist forever → path crosses walls.

Debug time: ~4 hours.

Spatial Index v1: HashMap + Vec Dedup

Idea: Grid-bucket for is_edge_valid(). Only check walls near the edge's AABB.

Failed: Each call allocated vec![false; 300]. 15K calls/repair × heap alloc = slower than linear scan. 300 walls (4.8KB) fit in L1 cache.

Fix (v2): Zero allocation, allow duplicate checks. Megacampus: 66.1s → 48.6s (−26%).

Development History
Research Timeline
Stage 1: Full Rebuild Baseline
Megacampus: 76.3s, 96.6%, 139.6 rebuilds
Every new wall → discard entire RRT* tree → rebuild from scratch.
Stage 2: Eager Incremental — update_static_obstacles()
8.71s (8.8x faster), 99.9%, 2.2 rebuilds
Core invention. Full-tree scan + hot-node reconnect for permanent walls.
Stage 3: Lazy Swap — set_static_validity_checker()
3.40s (22.4x faster), 97.4%, 3.9 rebuilds
Path not affected → only swap checker, skip tree scan.
Stage 4: Hybrid ✗
3.42s, 98.6% — abandoned
Light edge cleanup. No speed advantage over Lazy, worse than Eager.
Stage 5: Lazy+Eager Combo + LSR=80
Final single-agent architecture
Path clear → Lazy. Path blocked → Eager. LSR 10→80m. Detour + shortcut (marginal in multi-agent).
Stage 6: Route A ✗ — update_new_static_obstacles()
Wall-crossing bug — abandoned after ~4h debug
Only check new walls. Lazy swap interaction: old dirty edges never cleaned.
Stage 7: Multi-Agent Development
4 agents, Global King + flee + chain push, shared wall discovery
Reactive coordination in continuous space. Bottleneck 8-agent 100%. E3 confirmed over Senior.
Stage 8: Spatial Index v2
Megacampus WallMed: 66.1s → 48.6s (−26%)
Grid-bucket for is_edge_valid(). v1 failed. v2: zero-alloc, single-cell fast path.
Stage 9: Sharing Ablation — Final Validation
Shared 1.04x–2.09x faster across all 6 scenarios
Proved multi-agent value: cooperative exploration reduces per-agent spread by up to 4.4x.
